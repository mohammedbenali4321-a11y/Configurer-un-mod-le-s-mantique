# Configurer un modèle sémantique (Sales Analysis)

Ce dépôt contient les fichiers d'exercices Power BI pour le module de formation axé sur la **configuration d'un modèle sémantique**. 

Les modèles sémantiques permettent d'organiser des données complexes dans une structure intuitive, améliorant ainsi la visualisation des données et permettant un reporting efficace et informatif pour une meilleure prise de décision.

---

## 📁 Contenu du dépôt

* **`03-Starter-Sales Analysis.pbix`** : Le fichier Power BI Desktop de départ pour réaliser le TP / l'exercice pratique.
* **`03-Solution-Sales Analysis.pbix`** : Le fichier Power BI Desktop finalisé contenant la solution complète et le modèle sémantique configuré.

---

## 🚀 Objectifs d'apprentissage

En réalisant les exercices présentés dans ce projet, vous apprendrez à :
1. **Créer et gérer les relations** entre les tables (1 à plusieurs, plusieurs à plusieurs).
2. **Configurer les propriétés des colonnes et des tables** (formatage, masquage des clés techniques, tri par colonne).
3. **Optimiser le modèle sémantique** pour faciliter la création de rapports interactifs et performants.
4. **Créer des hiérarchies** pour permettre des analyses détaillées (drill-down).
